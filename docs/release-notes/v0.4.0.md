Теперь LeetTest проверяет конфиг одним запросом до нагрузки и плавно разгоняется до целевого RPS. [English](#english) · [Deutsch](#deutsch) · [简体中文](#简体中文)

## Новое

- **Проверка перед нагрузкой** — `-dry-run` шлёт по одному запросу на каждый вызов из конфига и показывает запрос, статус и ответ; без нагрузки и отчёта, код выхода 1, если хоть один вызов не прошёл.
- **Разгон** — `load.ramp` поднимает нагрузку с нуля до `rps` линейно перед основной частью прогона; вызовы разгона не входят в статистику и в пороги `pass`.

## English

LeetTest now checks a config with one request before the load and ramps up smoothly to the target RPS.

### New

- **Check before the load** — `-dry-run` sends one request per call in the config and shows the request, the status and the reply; no load, no report, exit code 1 if any call did not succeed.
- **Ramp-up** — `load.ramp` raises the load linearly from zero to `rps` before the main part of the run; the ramp's calls stay out of the stats and the `pass` limits.

## Deutsch

LeetTest prüft eine Konfiguration jetzt mit einer Anfrage vor der Last und fährt die Last gleichmäßig bis zur Ziel-RPS hoch.

### Neu

- **Prüfung vor der Last** — `-dry-run` sendet eine Anfrage pro Aufruf der Konfiguration und zeigt Anfrage, Status und Antwort; keine Last, kein Bericht, Exit-Code 1, wenn ein Aufruf nicht erfolgreich war.
- **Hochfahren** — `load.ramp` steigert die Last vor dem Hauptteil des Laufs linear von null auf `rps`; die Aufrufe des Hochfahrens zählen weder in der Statistik noch in den `pass`-Grenzen.

## 简体中文

LeetTest 现在可以在加压前用一个请求检查配置，并平稳地爬升到目标 RPS。

### 新功能

- **加压前检查** — `-dry-run` 为配置中的每个调用发送一个请求，并显示请求、状态和响应；不加压、不生成报告，任一调用未成功时退出码为 1。
- **爬升** — `load.ramp` 在运行主体之前把负载从零线性提升到 `rps`；爬升期间的调用不计入统计，也不计入 `pass` 阈值。
