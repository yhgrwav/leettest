## Исправлено

- Файл `-json-file` больше не становится доступен всем на чтение: права, которые у него были (например, `0600`), сохраняются.
- Файл конфига `.yaml` без `name:` и с вызовами к нескольким сервисам больше не даёт отчёт с пустым названием прогона.

## English

Two fixes in the report.

### Fixed

- The `-json-file` file no longer becomes readable by everyone: the permissions it had (for example `0600`) are kept.
- A config file named `.yaml`, without `name:` and with calls to more than one service, no longer gives a report with an empty run name.

## 简体中文

报告中的两处修复。

### 修复

- `-json-file` 写出的文件不再变成所有人可读：文件原有的权限（例如 `0600`）会保留。
- 名为 `.yaml`、未设置 `name:` 且调用多个服务的配置文件，不再生成运行名称为空的报告。
