未来计划推出面向团队和组织的付费 Enterprise 版 LeetTest。

## 哪些保持开源

内核与 CLI 以 Apache License 2.0 发布，并将保持开源。开源版本是一个独立完整的工具，没有人为限制；
商业使用不受限制。已发布的版本将不可撤销地继续适用 Apache 2.0。

## 为什么需要 CLA

pull request 需要作者签署 [CLA](../../CLA.md) 后才合入。它是许可，而非权利转让：
贡献的著作权仍归作者，项目获得的是再许可该代码的权利。没有它，付费版本在法律上不可能成立，
而且事后无法补救——那将需要征得每一位历史贡献者的同意。
