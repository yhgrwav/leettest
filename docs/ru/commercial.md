# Будет ли платная версия?

[← К документации](README.md)

В будущем планируется платная Enterprise-версия LeetTest для команд и организаций.

## Что остаётся открытым

Ядро и CLI распространяются под Apache License 2.0 и остаются открытыми. Открытая версия —
самостоятельный инструмент без искусственных ограничений; коммерческое использование не
ограничено. Уже выпущенные версии остаются под Apache 2.0 безотзывно.

## Зачем CLA

Pull request принимается после подписания [CLA](../../CLA.md). Это лицензия, а не передача
прав: авторские права на вклад остаются у автора, а проект получает право сублицензировать
код. Без этого платная версия невозможна юридически, а исправить это позже нельзя —
понадобится согласие каждого, кто когда-либо что-то прислал.
