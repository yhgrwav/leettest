LeetTest отвечает на вопрос, с которым приходят к нагрузочному тесту: **при какой нагрузке сервис
перестаёт справляться и где узкое место.** Отчёт показывает запрошенную нагрузку рядом с
выданной и называет ожидания на стороне клиента, чтобы по числам можно было судить, сколько в них
сервиса, а сколько генератора. Дальше: несколько методов в одном прогоне, у каждого свой RPS;
простой CLI без `.proto`, кодогенерации и скриптов. Приоритеты проекта, по порядку: корректность
измерений, удобство, скорость. Что работает сейчас — в таблице ниже, что будет дальше — в
[плане развития](roadmap.md).

## Участие

Issues и обсуждения приветствуются. Pull request'ы принимаются после подписания [CLA](../../CLA.md) —
одна строчка комментарием в PR, проверяется автоматически. Как начать — в
[CONTRIBUTING.md](../../CONTRIBUTING.md): там отдельно путь человека и путь с ИИ-агентом (агенту, который меняет код, — [AGENTS.md](../../AGENTS.md)). CLA — это
лицензия, а не передача прав: авторские права остаются у вас.
