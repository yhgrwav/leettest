# На какие вопросы отвечает LeetTest

[← К документации](README.md)

Вопросы, на которые отчёт отвечает уже сейчас.

| Вопрос | Что покажет отчёт | Где |
|---|---|---|
| При какой нагрузке сервис перестаёт справляться? | Поиск точки отказа: на какой ступени цель держалась, на какой сломалась и почему — ошибки, p99, соединение, не вернулась к прежнему p99 | [Поиск точки отказа](../../README.md#поиск-точки-отказа) |
| Как отвечает каждый метод под нагрузкой, похожей на настоящую? | Несколько методов одновременно, у каждого свой RPS; p50, p90, p95, p99 по каждому | [Запуск](../../README.md#запуск) |
| Что видит пользователь, когда сервис замирает или тормозит? | Латенси считается от запланированного момента вызова: зависание цели не прячется, а попадает в p99 | [Как читать отчёт](../../README.md#как-читать-отчёт) |
| Какие ошибки и от кого? | Категории: неверный запрос, перегрузка, сбой, обрыв, тайм-аут; статус прислала цель (или прокси) либо поставил клиент | [Как читать отчёт](../../README.md#как-читать-отчёт) |
| Сколько вызовов осталось без ответа и почему? | Не ушли, оборваны или тайм-аут — раздельно; секунда, с которой цель перестала отвечать | [Как читать отчёт](../../README.md#как-читать-отчёт) |
| Нагружены ли все бэкенды за балансировщиком? | `app.connections: N`: по строке на соединение — адрес, вызовы, доля отказов, p99 | [Как читать отчёт](../../README.md#как-читать-отчёт) |
| Не врёт ли сам замер? | Вердикт об ожиданиях на стороне клиента и p99 без них; недействительный прогон (код 2), если числа не про цель | [Когда прогон недействителен](../../README.md#когда-прогон-недействителен) |
| Как сервис ведёт себя на разных данных? | `dataset`: свой запрос на каждый вызов, по JSON на строку файла | [Справочник](reference.md#каждый-раз-другой-запрос-dataset) |
| Можно ли запускать в CI? | Один JSON-объект со стабильной схемой и коды выхода; пределы `pass` решают «держит / не держит» кодом `4` | [JSON для скриптов и CI](../../README.md#json-для-скриптов-и-ci) |

LeetTest видит только сторону клиента: сколько ресурсов у цели, он не знает и не угадывает. Что
будет дальше — в [плане развития](roadmap.md).
