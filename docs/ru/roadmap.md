## Следующая версия (v0.2)

- **Поиск точки отказа.** Инструмент сам поднимает нагрузку ступенями и называет RPS, на котором
  сервис перестал справляться, по заранее заданному критерию «сломался».
- **Разные данные в каждом вызове.** Тело запроса меняется от вызова к вызову, а не одно на весь
  метод: нагрузка не упирается в один ключ кеша или одну строку в базе.
- **Несколько соединений.** Сейчас генератор держит одно соединение, и за балансировщиком
  нагрузку получает один бэкенд. Будет `connections: N`.

## Дальше

- **`.proto` и protoset** для сервисов без server reflection.
- **Разгон** с нуля до целевого RPS.
- **Пороги pass/fail для CI**: прогон падает, если p99 или доля ошибок выше заданного.
- **[Связывание вызовов](chaining.md)**: поле из ответа одного метода — в запрос другого.
- **Обновление токена** во время долгого прогона.
- **Экспорт метрик** в Prometheus.
